Training fields

How to populate each training field. Taxonomy and source values are ReliefWeb integer ids. Document url and uuid follow Trusted URLs and UUIDs. See conditional fields on the Training hub for country and fee_information.

Canonical schema: training.json.

url

Required yes
Type string (IRI / URL)
Identifier Trusted URL / IRI

Immutable unique identifier in URL form under your trusted document prefix. Used to generate the training UUID. Does not need to resolve to a live page. Never change after first submission.

Example

"https://myorganization.org/training/12345"

Validation

  • Must start with a trusted document prefix

  • Max length 2048

  • Never change after the first successful submission

See also

  • Trusted URLs and UUIDs

uuid

Required yes
Type string (UUID v5)
Identifier UUID v5

Training UUID v5 computed as uuid5(ReliefWeb namespace, url). Must match what the server computes from the exact url string.

Example

"c2484d60-fa5d-591e-bcdd-401ffa63b92c"

Validation

  • Must be UUID format

  • Must equal uuid5('8e27a998-c362-5d1f-b152-d474e1d36af2', url)

  • Rejected if it does not match the server computation

See also

  • Trusted URLs and UUIDs

title

Required yes
Type string

Training title only. Do not put location, date, or organization name in this field.

Example

"Example Introduction to Humanitarian Response"

Validation

  • Length 10–255 characters

  • Must contain letters

  • No leading, trailing, or consecutive spaces

source

Required yes
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/sources — see docs

Source organization ID(s) from /v2/sources (ReliefWeb integer taxonomy IDs, not UUIDs).

Example

[1503]

Validation

  • 1–30 unique integer IDs

  • Each value must be a valid /v2/sources id

format

Required yes
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/references/training-formats — see docs

Training-format ID(s) from /v2/references/training-formats (on-site and/or online). On-site id is 4606; online is 4607.

Example

[4607]

Validation

  • 1–2 unique integer IDs

  • Must be valid training-formats reference ids

country

Required conditional — Required when format includes on-site (id 4606); omit (do not send) otherwise
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/countries — see docs

Country ID(s) from /v2/countries. Mandatory when format includes on-site; otherwise the property is not allowed.

Example

[13]

Validation

  • When required: 1–300 unique integer IDs

  • Each value must be a valid /v2/countries id

  • Omit entirely for online-only offerings

dates

Required no
Type object

Training dates. Omit the whole object if the offering is ongoing or always available. When present, all three properties are required.

Example

{
  "start": "2026-09-01T09:00:00+00:00",
  "end": "2026-09-05T17:00:00+00:00",
  "registration_deadline": "2026-08-15T00:00:00+00:00"
}

Validation

  • Optional object; omit for ongoing / always-available courses

  • If present, must include start, end, and registration_deadline

  • Each value is ISO 8601 date-time

  • Ads expire after registration_deadline

event_url

Required yes
Type string (IRI / URL)
Identifier Trusted URL / IRI

Public page with more information about the opportunity. Do not use a social media URL here (you may mention social links in body).

Example

"https://myorganization.org/training/12345/register"

Validation

  • Valid IRI / URL

  • Max length 2048

  • No social media profile URLs

cost

Required yes
Type string (enum)

Whether the training is free or fee-based.

Example

"fee-based"

Validation

  • Exactly one of: free, fee-based

fee_information

Required conditional — Required when cost is fee-based; omit (do not send) when cost is free
Type string

Exact course fee and what it does and does not cover (plain text). Cannot be replaced by a link alone.

Example

"USD 250 covers tuition and materials."

Validation

  • Length 10–100000 characters when present

  • Must contain letters

  • Plain text with the actual fee details — not only a URL

category

Required yes
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/references/training-types — see docs

Single training-type ID from /v2/references/training-types.

Example

[4609]

Validation

  • Exactly one integer ID (minItems 1, maxItems 1)

  • Must be a valid training-types reference id

training_language

Required yes
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/references/languages — see docs

Language(s) in which the course or event is held, from /v2/references/languages.

Example

[267]

Validation

  • 1–10 unique integer IDs

  • Must be valid languages reference ids

professional_function

Required no
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/references/career-categories — see docs

Career-category ID(s) from /v2/references/career-categories. Tag only the most relevant (over-tagging reduces discoverability).

Example

[36601]

Validation

  • Optional; max 3 unique integer IDs

  • Must be valid career-categories reference ids

theme

Required no
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/references/themes — see docs

Single theme ID from /v2/references/themes. Choose only the most relevant.

Example

[4587]

Validation

  • Optional; at most one integer ID (maxItems 1)

  • Must be a valid themes reference id

language

Required yes
Type array of integer
Identifier ReliefWeb integer taxonomy ID (not a UUID)
Lookup /v2/references/languages — see docs

Language(s) of this advertisement (English, Spanish, or French), from /v2/references/languages. This is the language of the ad text, not the course language.

Example

[267]

Validation

  • 1–10 unique integer IDs

  • Advertisement must be in English, Spanish, or French

  • Must be valid languages reference ids

body

Required yes
Type string (markdown or HTML)

Complete training description (introduction, methodology, objectives, audience). Do not replace with a link for further details.

Example

"Course overview and learning objectives in markdown or HTML."

Validation

  • Length 10–100000 characters

  • Must contain letters

  • Allowed HTML tags: h1–h6, br, p, strong, em, a, ul, ol, li, blockquote

  • Must contain the real description — not only a link

how_to_register

Required yes
Type string (markdown or HTML)

Registration steps, conditions, and contact details. Do not replace with a bare link. If none required, say so explicitly (for example “No registration required.”).

Example

"Register on the event URL before the listed deadline."

Validation

  • Length 10–100000 characters

  • Must contain letters

  • Same HTML allowlist as body

  • Must include procedure/contact — not only a link
