Resources

Base host: https://api.reliefweb.int. Version path: /v2. List available resources with GET /v2 (include your appname).

Each resource page covers the endpoint, its fields, and a Defaults section (profile field sets and public presets). To choose which fields appear in a response, see Choose fields.

Do not confuse the profile request parameter with the profile field on countries and disasters.

Endpoints

  • Resource endpoint (GET or POST /v2/{resource}): Search, filter, sort, and facet across records. All request parameters apply.
  • Single record (GET /v2/{resource}/{id|uuid}): Fetch one record by numeric ReliefWeb ID or UUID. Accepts profile, fields, preset, and slim (defaults and 404 behaviour: Get one item).

Field attributes

Resource field tables include an Attributes column:

Attribute Meaning
searchable Can be targeted in query
facetable Can be used in facets
exact Supports .exact / exact phrase matching
sortable Can be used in sort
multi Field may hold multiple values
common Shared across several content types
