Countries

Country records and situational overviews (reliefweb.int/countries), including id, name, shortname, iso3, status, and country profile content.

Query /v2/countries to look up country id or iso3 codes for filtering or publishing on other resources.

  • Endpoint: POST or GET https://api.reliefweb.int/v2/countries
  • Single country: GET https://api.reliefweb.int/v2/countries/{id|uuid}

Defaults

Requests to /v2/countries default to profile=minimal and preset=minimal. Single-record requests (/v2/countries/{id}) default to profile=default and preset=minimal. See Choose fields and presets.

Profiles

ProfileFields
minimal name
list name, status, url
suggest name, shortname (sets slim)
full All fields
default All fields (omits profile.key_content.archive, profile.appeals_response_plans.archive)

Add more with fields.include (for example iso3 is not in list).

Presets

PresetStatus filterSortDefault query fields
minimal n/a n/a name
latest n/a id:desc name, shortname, iso3
analysis n/a n/a name, shortname, iso3, status
