Read / search

Query curated ReliefWeb content as JSON at https://api.reliefweb.int/v2. Every call needs a pre-approved appname on the URL.

First call

List the latest reports. This example sets "profile": "list", which returns a practical default set of fields for browsing:

POST

https://api.reliefweb.int/v2/reports?appname=REPLACE-WITH-APP-NAME

A successful response includes totalCount, count, and a data array of items. See Response, limits, and errors for the response shape and an abbreviated example.

You can also refine a query on the ReliefWeb site and use the search converter to turn a listing URL into an API payload.
