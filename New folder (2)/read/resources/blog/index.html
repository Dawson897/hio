Blog

Posts from the ReliefWeb blog (reliefweb.int/blog) about ReliefWeb features, updates, and projects (title, author, body, tags, date).

  • Endpoint: POST or GET https://api.reliefweb.int/v2/blog
  • Single post: GET https://api.reliefweb.int/v2/blog/{id|uuid}

Defaults

Requests to /v2/blog default to profile=minimal and preset=minimal. Single-record requests (/v2/blog/{id}) default to profile=default and preset=minimal. See Choose fields and presets.

Profiles

ProfileFields
minimal title
list title, url, date.created, tags.name
full All fields
default All fields

Add more with fields.include.

Presets

PresetStatus filterSortDefault query fields
minimal published n/a title
latest published date.created:desc title, body
analysis published n/a title, body
